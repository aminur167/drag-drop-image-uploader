# Drag & Drop Image Uploader

Interactive file uploader with drag-and-drop support, real-time image previews, and individual file removal.

## Features

- Drag and drop files onto the upload zone
- Click to browse and select files
- Real-time thumbnail preview for each image
- Remove individual images before upload
- File type and size validation
- Responsive design

## Files

```
index.html   - Upload zone and preview container
style.css    - Drag-over states, thumbnail grid
script.js    - FileReader API, drag events, DOM updates
```

## How It Works

Uses the HTML5 Drag and Drop API combined with `FileReader` to read dropped files as data URLs and render preview thumbnails dynamically.
